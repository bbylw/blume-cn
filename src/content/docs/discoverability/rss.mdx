---
title: RSS 订阅源
description: 为 blog 和更新日志生成 RSS 订阅源，并输出让阅读器自动发现的 link 标签
source: https://useblume.dev/docs/discoverability/rss
---

Blume 会为 `seo.rss.types` 中每一个有页面的内容类型构建 RSS 订阅源 —— 默认是 `blog` 和 `changelog` —— 访问路径为 `/<type>/rss.xml`。如何撰写带日期的 blog 和更新日志条目，参见[订阅源](/docs/content#feeds)。

订阅源中的链接必须是绝对的，因此订阅源需要一个站点 URL：设置 [`deployment.site`](/docs/deployment#set-your-site-url)，或者部署到 Blume 能自动检测到它的托管平台（Vercel、Netlify、Cloudflare）。没有站点 URL 时，构建完全不会输出任何订阅源。在 `blume dev` 期间会由本地服务器的 URL 顶替，所以在那儿订阅源总是能看到。

```ts blume.config.ts lineNumbers
seo: {
  rss: {
    enabled: true,
    types: ["blog", "changelog"],
    limit: 50,
  },
}
```

| 选项 | 默认值 | 说明 |
| - | - | - |
| `enabled` | `true` | 生成订阅源。 |
| `types` | `["blog", "changelog"]` | 各自获得一个订阅源的内容类型。 |
| `limit` | `50` | 每个订阅源最多条目数，最新的在前。 |

Blume 会注入 `<link rel="alternate">` 标签，让浏览器和订阅源阅读器自动发现这些订阅源，并把它们列在[智能体可读性清单](/docs/discoverability/agent-discovery#agent-readability)里，让智能体也能找到。每个条目都指向该页面的绝对 URL。
